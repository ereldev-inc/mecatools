Âge du pneu : décoder le code DOT (semaine et année)

Saisissez le code DOT gravé sur le flanc (ou simplement ses derniers chiffres) pour obtenir la date de fabrication et l'âge du pneu.

Repérez le code DOT sur le flanc. Seuls les 4 derniers chiffres comptent.

À propos de cet outil

Le code DOT est moulé sur le flanc du pneu. Ses quatre derniers chiffres donnent la date de fabrication : les deux premiers sont la semaine (01 à 53), les deux derniers l'année. Par exemple 2319 signifie semaine 23 de 2019. Les pneus fabriqués avant 2000 n'ont que trois chiffres.

La gomme vieillit même quand le pneu ne roule pas. On surveille généralement le pneu de plus près après environ 5 ans et on le remplace au plus tard à 10 ans, quelle que soit l'usure. Suivez toujours les conseils du fabricant et vérifiez l'absence de craquelures, de durcissement et de déformations.
